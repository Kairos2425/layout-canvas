the loop

设计 → 验证，一条不骗人的闭环

每一步都是真工具结果。跑不出来就报 unavailable——永不给假绿。

01 / IR

Block IR

Pydantic 类型化设计描述：实例、参数、布局、网络、端口。可序列化、可 diff、可交给 agent 改。

02 / compile

参数化模块

10 个真实模拟单元：差分对、电流镜、5T-OTA、StrongArm、MIM 电容阵、保护环——双 PDK 几何。

03 / DRC

规则检查

KLayout 内嵌引擎做宽度/间距/via 包围检查，违规红框直接画回画布原位。

04 / LVS

版图对原理图

LayoutToNetlist 真实提取 + 拓扑比对；失配网逐条定位、画布高亮。

05 / PEX

版图后仿真

提取网表直接跑 foundry 模型（BSIM4 / PSP103），内部节点可探测，波形回显。

block library

参数化模拟模块 · 双 PDK

每个块都是代码生成的真实几何：指叉、共心保护环、栅绑带、via 栈——参数化到 finger 数与器件尺寸。
